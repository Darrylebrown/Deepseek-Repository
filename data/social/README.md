# Social

Social calendars, post batches, and caption sets.

- Date-lead anything time-bound: `2026-08-social-calendar.md`
- Give each post its own entry with the platform, intended date, and copy
- Note any image or asset a post depends on

Captions carry the same standards as the books: culture first, at most one soft CTA to
https://gullahgeecheebiz.com/, no mock dialect, no name-drops, no vendor or Manus links.

Brand rules and ready-signalling: see [`../README.md`](../README.md).
