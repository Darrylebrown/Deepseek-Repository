# Inbox checklist

What Computer does with an inbound agent drop, in order. Anything that fails a step goes
back to the drop folder with a note rather than moving forward.

## 1. Brand gate

Read the drop against the rules in [`README.md`](README.md) before anything else:

- [ ] Culture leads; commerce is secondary
- [ ] At most one soft CTA, pointing only to https://gullahgeecheebiz.com/
- [ ] No mock or phonetically spelled Gullah Geechee dialect
- [ ] No invented quotes attributed to real people
- [ ] No celebrity or public-figure name-drops
- [ ] No invented statistics, dates, or citations
- [ ] No Manus links, tooling, platform, or vendor mentions anywhere in the copy
- [ ] Author and publisher lines correct: Darryl Elliott Brown · Gullah Geechee Biz

## 2. EPUB and cover

- [ ] Front matter: title, author, publisher, copyright year
- [ ] Chapter structure and headings clean; working table of contents
- [ ] Cover art sized for KDP, title and author legible at thumbnail size
- [ ] EPUB validates and opens on a reader

## 3. KDP paste

- [ ] Title and subtitle
- [ ] Description, keywords, and categories
- [ ] Pricing and territories
- [ ] Upload manuscript and cover; check the KDP previewer before saving

## 4. Distributor log

- [ ] Record title, format, date submitted, and destination
- [ ] Note the drop file this shipped from, so the source is traceable
- [ ] Link the live listing once it is approved

## Handing something back

If a drop fails the brand gate, leave a note next to it in the drop folder naming the
specific rule and line. Do not silently rewrite an agent drop — the correction should be
visible so the next run can avoid the same problem.
