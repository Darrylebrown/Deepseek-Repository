# Volumes

Book-length manuscripts and volume drafts headed for KDP.

- One folder or file per volume: `lowcountry-foodways-vol-1.md`
- Include front matter (title, author, publisher, copyright year) in the draft itself
- Chapter headings as `##` so the EPUB build can generate a table of contents
